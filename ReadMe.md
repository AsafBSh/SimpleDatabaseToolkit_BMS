# Simple Database Toolkit

## Overview

The Simple Database Toolkit is a comprehensive tool designed to streamline and automate various tasks related to Falcon BMS database management. It provides a user-friendly interface for adjusting and fixing database entries, making it easier for developers to maintain and update their databases efficiently.
### Key Features:

    - Replace Page: Allows users to replace specific feature numbers in XML files across multiple folders.
    - Offset Fixer: Enables adjustments of XY offsets, Z offsets, rotations, and values for features in XML files.
    - Runway Dim Fixer: Automates updates of runway dimensions in PHD XML files to ensure consistency.
    - Folders Creator: Creates multiple numbered folders within a specified directory.
    - Reformat Parents: Reformats parent.dat files to a standardized format.
    - Parking Fixer: Relocates parking points closer to hangars in objectives.

## Benefits for Developers

    - Efficiency: Automates repetitive tasks, saving time and reducing manual errors.
    - Consistency: Ensures uniformity across database entries and files.
    - Ease of Use: Provides a straightforward interface for performing complex operations.
    - Flexibility: Supports both single and multiple folder modes for various tasks.

## Usage

    - Select the desired operation (e.g., Replace, Offset Fixer, etc.).
    - Choose the relevant files or folders.
    - Follow the prompts to input necessary parameters (e.g., feature numbers, offsets).
    - Execute the operation to apply changes.
    - Review logs for details on changes made.
